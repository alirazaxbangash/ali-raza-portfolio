ALI RAZA PORTFOLIO WEBSITE
==========================
Files:
- index.html: website structure/content
- style.css: gaming-neon design, responsive layouts
- script.js: mobile navigation and current year
- assets/: place your profile photo here

ADD YOUR PHOTO:
1. Put your own portrait photo in the assets folder.
2. Rename it exactly: ali-raza-photo.jpg
3. Refresh the website. It will replace the placeholder automatically.

PREVIEW IN VS CODE:
1. Open this folder in VS Code.
2. Install Live Server by Ritwick Dey if needed.
3. Right-click index.html > Open with Live Server.

OPEN ON YOUR PHONE (same Wi-Fi):
1. Start Live Server.
2. Open Command Prompt on Windows and run: ipconfig
3. Find IPv4 Address for your active network.
4. On the phone, open http://YOUR-PC-IP:5500 (example http://192.168.1.7:5500).
5. Keep Live Server running. If Windows Firewall asks, allow private network access.
